# V5 bench proof, 2026-09-29

The V5D milestone checks four V5 claims on the bench's own fixtures with `cuanta bench run --compare`.
Every run used Claude Code 2.1.283 under a subscription, in a fresh copy outside the repository.
Costs are the values the CLI reported. Each comparison ran one repetition per arm unless noted, so
each verdict is one measurement, not a distribution.

Total spend: **$3.3280** of the $4.00 cap (five bench runs, ten launches).

| Claim | Target | Measured | Verdict |
|---|---|---|---|
| Warm queue | the second queued mandate's first request reads ≥ 80% of its fixed prefix from cache | 85% (9,107 of 10,768 tokens); the first mandate read 0% | met |
| Graceful finish | no run ends cut by its cap when a graceful finish was possible | 0 of 2 runs cut by a $0.12 cap | met (the finish turn was not exercised) |
| Read discipline | ≥ 50% fewer exploration-leak tokens with the discipline on | 454 against 5,819 leak tokens: 92% fewer | met on the leak metric (see caveats) |
| Scout & senior | ≥ 40% cheaper than the pipeline on an exploration-heavy feature, with equal acceptance | $0.4753 against $0.6084: 22% cheaper, accepted 1/1 against 1/1 | missed |

## Caveats

- **Read discipline.** The leak metric met its target, but no read was blocked in the run with the
  discipline on, so the difference comes from what that run chose to read, not from a blocked
  call. That run also cost 2.5 times as much as the run without the discipline, and neither run
  passed the task's checks. One repetition per arm cannot separate the discipline from run-to-run
  variation. R3 measures it again on a real project.
- **Graceful finish.** Neither run needed a finish: both ended under the cap. The target is met as
  defined (no run was cut), but the finish turn itself was not exercised live here; its behaviour
  rests on the fake-stream tests and contract CC-12.
- **Scout & senior, first attempt.** The new `shop-restock-report` task asked for "soonest first"
  without saying how to order ties, and its hidden test expected ties by sku. Both arms produced the
  same order and failed the same assertion. The request text now says "ties by sku", and the
  comparison was run again with a new seed. The first attempt counts in the spend.
- **Scout mode.** The Claude team ran the scout as a native subagent (`runs.scout_mode = native`,
  the default). The separate-launch mode was not measured, so the default stays native.
- **Native scout capture.** In both scout arms the scout was dispatched as a subagent and its pack
  was captured from the stream, which verifies contract CC-23.

## Commands

```bash

cuanta bench run --compare finish --suite mini --task calc-mean --depth quick --model haiku --reps 2 --seed 14 --arm-cap tight-cap=0.12 --budget-usd 0.34 --yes
cuanta bench run --compare read-discipline --suite full --task boltons-slugify-max-length --depth quick --model haiku --reps 1 --seed 12 --arm-cap discipline-on=0.55 --arm-cap discipline-off=0.55 --budget-usd 1.10 --yes
cuanta bench run --compare scout --suite proof --task shop-restock-report --depth quick --model sonnet --reps 1 --seed 21 --arm-cap scout=0.70 --arm-cap pipeline=0.70 --budget-usd 1.40 --yes
```

`cuanta bench report --id <bench id>` writes each comparison's report with its target verdict.
