# The real cost before and after V5, 2026-09-29

R3 ran the same four frozen requests on a private copy of a production Next.js landing page, with
both provider teams, in two modes, on the same day (2026-09-29, local time). Every trial ran in a
sandbox copy with the code index on; nothing was applied to the project.

- **Classic:** `cuanta mandate --classic`, V4-style: the full pipeline, docs on, no read discipline,
  no scout and no governor.
- **V5:** the new defaults: the shape chosen by the forecast (scout & senior when exploration
  dominates), docs off unless asked, read discipline on for team roles, the governor on.
- **Claude team:** Sonnet 5 for the audit; Haiku 4.5 scout or Sonnet 5 analyst, Opus 5.5 senior,
  Sonnet 5 tester, Haiku 4.5 docs. **GPT team:** `gpt-6-sol` for the audit; `gpt-6-luna` scout or
  `gpt-6-sol` analyst, `gpt-6-sol` senior and tester, `gpt-6-luna` docs.
- **Caps per trial:** audit $0.50, fix $1.60, feature $1.20. Claude costs are what the CLI reported
  (subscription usage estimates); GPT costs are token-priced estimates at Standard rates.

Total R3 spend: **$13.0036** of the $18.00 cap, over 20 launches (16 trials; four of them ran twice,
see "Reruns").

- **GPT, V5, all three changes:** the first attempts stopped early ($0.0651, $0.0633, $0.0139).
  Two found bugs in the new scout shape: the Codex senior stopped because the project's agent rules
  ask for an analyst plan, which this shape does not produce, and a scout refused to put a file in
  the edit set because an index card flagged it "generated; do-not-edit" from a rule that only
  mentioned generated metadata. Both were fixed (the senior is told the pack replaces the plan, the
  scout treats card flags as hints, and the card flag now needs the path or an explicit
  do-not-edit note), and the three trials ran again.
- **GPT, classic, JSON-LD:** the first attempt finished ($1.1094) but recording its trial failed
  with a Windows `PermissionError`, so there was no patch to judge; it ran again ($1.1330).

## Findings

- **Codex caps.** Without the governor, the GPT audit ran 38% over its cap ($0.69 against $0.50);
  with it, the V5 audit ran 11% over and the V5 fix 6% over. Codex still reports usage only at the
  end of a turn (CX-10), so the governor stops on an estimate.
- **The GSAP file checks** are the ones used since T1: they look for an unbound `catch {` that sets
  `visibility` in the reveal components. The Claude diffs added a guarded fallback, but in a bound
  `catch (error)` or in a shared helper, so they fail those checks. The rule stays the same across
  history; the result is recorded as measured.
- **Read discipline** recorded zero blocked reads in all 20 summaries. Its causal cost savings
  were not measured separately from the other V5 changes.
- **Recording on Windows** failed once with `PermissionError` (IMP-008).
